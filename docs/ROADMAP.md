# サツコイ！ ロードマップ

サービスの段階的な拡張計画です。Phase 1 は本リポジトリで実装済み（外部連携はデモ用スタブ）、
Phase 2 以降は本実装・拡張の方針を示します。

---

## Phase 1: 実装済み（デモ）

会員登録〜マッチング〜日程調整〜デート〜アンケートの基盤フローと運営管理画面に加え、以下を実装。

- **LINE ログイン / LINE 通知 UI** … 連携状態（`Member.lineConnected`）と通知先切替（`Member.notifyViaLine`）。OAuth・メッセージ送信はスタブ。
- **成功報酬型課金の訴求** … 登録料 11,000 円＋日程確定時のみ 5,500 円の都度課金。月額なしを訴求（決済はスタブ）。
- **AI アドバイザー（デモ）** … 仲人ノウハウ風の相談 UI。応答は定型ベース。
- **AI 相性スコア推薦（デモ）** … プロフィール項目にもとづく相性スコア付きおすすめ表示。
- **提携店ギフト券管理** … `GiftTicket`（紹介特典 / キャンペーン / 補償、有効・使用済み・期限切れ）。
- **不動産シナジー訴求** … グループ不動産事業と連携した成婚特典（新居探し・キャッシュバック）の訴求導線。
- **源泉徴収票の男性必須化** … 所得証明（源泉徴収票）を男性は必須・女性は任意に。年収欄の公開には所得証明の確認が必要。
- **PWA** … manifest / アイコン同梱。ホーム画面追加でアプリライクに利用可能。

## Phase 2: 本実装（外部連携の実運用化）

- **LINE Login（LIFF）** … LINE アカウントでのログイン・会員連携を LIFF で本実装。
- **LINE Messaging API 通知** … 申込・マッチ成立・日程確定・リマインドなどの通知を LINE 公式アカウントから配信（メール通知と選択制）。
- **Stripe 本決済**
  - 登録時に与信（オーソリ）を実施し、決済可否によるブラックリスト確認を兼ねる。
  - デート日程確定時に 5,500 円を都度決済（成功報酬型）。
  - 違約金・返金もキャンセル区分（`lib/scheduling.ts`）に沿って Stripe 上で処理。
- **書類の厳格運用** … 証明書類はプライベートバケット＋署名付き URL で管理し、運営確認フロー（提出→確認→承認→公開項目の解放）を厳格に運用。男性の源泉徴収票必須を審査で担保。

## Phase 3: AI 本実装

- **AI アドバイザー（RAG）** … 仲人のノウハウ・相談事例を学習データ化し、RAG（検索拡張生成）で個別相談に応答する本実装へ。
- **成婚データ駆動の推薦モデル** … デート実施・アンケート・成婚の実績データを教師信号として相性スコアを学習し、推薦精度を継続改善。
- **画像分析タイプ診断** … プロフィール写真の画像分析による「好みのタイプ」診断・推薦への反映。

## Phase 4: 事業拡張

- **ネイティブアプリ化** … PWA からネイティブアプリ（ストア配信）へ移行し、プッシュ通知・カメラ連携等を強化。
- **不動産事業連携の成婚キャッシュバック運用** … 成婚カップルの新居探し（賃貸・購入）をグループ不動産事業へ送客し、キャッシュバック特典を実運用。
- **多都市展開** … 札幌モデル（地域密着・提携店ネットワーク・成功報酬型）を他都市へ横展開。

## 札幌ローカル戦略（内部方針）

札幌市の 20〜30 代は女性人口が男性を上回る（未婚女性が相対的に多い）人口動態にあり、
マッチングサービスとしては**男性会員の獲得がボトルネック**になりやすい。

- マーケティング予算・紹介特典は**男性獲得を優先**して配分する（女性は口コミ・紹介経由の自然流入を主軸）。
- 男性向けには「月額なし・会えたときだけ 5,500 円」の成功報酬型課金と、源泉徴収票確認による
  「年収表示の信頼性」を訴求軸とする（真剣度・安全性の担保が女性側の継続利用にも波及）。
- 提携店ギフト券・不動産成婚特典など、札幌ローカルの提携ネットワークを差別化要素として強化する。
